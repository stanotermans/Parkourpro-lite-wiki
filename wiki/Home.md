## Pro vs Lite

| Feature | Lite | Pro |
|---|---|---|
| Start, end, reset and checkpoint plates, creation wizard | ✓ | ✓ |
| Live timer (action bar, title, boss bar) | ✓ | ✓ (+ XP bar) |
| Holograms and leaderboard hologram | ✓ | ✓ |
| Records in MySQL or YAML, `deletetime` / `settime` | ✓ | ✓ |
| Checkpoint splits, statistics, `top` / `pb` | ✓ | ✓ |
| Cooldown, daily limit, leave radius, per-parkour sounds and titles | ✓ | ✓ |
| Export / import, Discord webhook, PlaceholderAPI, 23 languages | ✓ | ✓ |
| Proximity finish, time limits, penalties, fall-blocks | – | ✓ |
| Ghost replay, race mode, seasons, daily/weekly/monthly leaderboards | – | ✓ |
| Menu, rewards by time and rank, checkpoint effects, speed check | – | ✓ |
| Special pressure plates, medals, hide players, dynamic holograms | – | ✓ |
| Network sync, web API, Discord bot, WorldGuard, ItemsAdder | – | ✓ |
